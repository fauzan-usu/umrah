BAB I — Pengenalan Sistem

1.1 Apa itu Sistem Alfadh Umrah?

Sistem Alfadh Umrah adalah aplikasi web berbasis PHP dan MySQL yang dirancang khusus untuk PT. Alfadh Berkah Haramain guna memantau pembayaran jamaah umrah secara real-time. Aplikasi ini mendukung dua metode pembayaran: Lunas (sekali bayar) dan Bertahap (DP + Cicilan + Pelunasan).

1.2 Fitur Utama

FiturKeterangan
Dashboard Real-TimeGrafik pemasukan, statistik jamaah, performa sales
Manajemen PaketKelola paket umrah dengan harga, durasi, kuota, fasilitas
Manajemen JamaahData lengkap jamaah dengan progress pembayaran visual
Kwitansi OtomatisGenerate nomor kwitansi unik (KWT-YYYYMMDD-XXXX)
Laporan KeuanganFilter per periode, paket, sales, status bayar
Multi UserRole Admin (super user) dan Sales (input kwitansi)
Cetak KwitansiFormat resmi dengan watermark, stamp, dan terbilang

1.3 Arsitektur Teknologi

Stack Teknologi:
Backend: PHP 8.x Native (tanpa framework)
Database: MySQL 5.7+ / MariaDB 10.3+
Frontend: Bootstrap 5.3, Chart.js, Font Awesome 6
Server: Apache (via XAMPP/MAMP/LAMPP)

BAB II — Instalasi di Windows (XAMPP)

2.1 Download XAMPP

1
Kunjungi website Apache Friends:
Buka browser dan akses https://www.apachefriends.org
Download XAMPP for Windows versi terbaru (PHP 8.x).
2
Jalankan Installer:
Klik dua kali file xampp-windows-x64-xxx-installer.exe
Pilih komponen: Apache, MySQL, PHP, dan phpMyAdmin.
Folder instalasi default: C:\xampp

2.2 Menjalankan XAMPP

3
Buka XAMPP Control Panel:
Klik Start Menu → XAMPP → XAMPP Control Panel
Klik tombol Start pada modul Apache dan MySQL.
Pastikan kedua modul berjalan (warna hijau / running).
Catatan Firewall: Jika Windows Defender atau antivirus memblok Apache, klik Allow Access pada notifikasi yang muncul.

2.3 Menempatkan File Aplikasi

4
Extract File ZIP:
Extract alfadh-umrah-app.zip ke folder:
C:\xampp\htdocs\alfadh-umrah-app\
Pastikan struktur folder seperti berikut:
C:\xampp\htdocs\alfadh-umrah-app\index.php
C:\xampp\htdocs\alfadh-umrah-app\alfadh_umrah.sql

2.4 Import Database

5
Buka phpMyAdmin:
Buka browser → ketik http://localhost/phpmyadmin
Klik menu Import di bagian atas.
Klik Choose File → pilih file alfadh_umrah.sql
Klik tombol Go di bagian bawah.
Database alfadh_umrah akan terbuat otomatis dengan data dummy.

2.5 Konfigurasi Database (Opsional)

6
Edit file konfigurasi:
Buka file C:\xampp\htdocs\alfadh-umrah-app\includes\config.php
Jika MySQL Anda memiliki password, ubah baris:
define('DB_PASS', ''); → define('DB_PASS', 'password_anda');
Simpan file (Ctrl + S).

2.6 Mengakses Aplikasi

7
Buka Aplikasi:
Buka browser → ketik http://localhost/alfadh-umrah-app/
Halaman login akan muncul.
Login dengan akun default (lihat Lampiran).
Shortcut: Anda bisa membuat shortcut di Desktop yang mengarah ke http://localhost/alfadh-umrah-app/ untuk akses cepat.

BAB III — Instalasi di macOS (MAMP)

3.1 Download MAMP

1
Kunjungi Website MAMP:
Akses https://www.mamp.info
Download MAMP (bukan MAMP PRO) versi terbaru.
File download biasanya bernama MAMP_MAMP_PRO_6.x.pkg
2
Instalasi MAMP:
Klik dua kali file .pkg → ikuti wizard instalasi.
Default folder aplikasi: /Applications/MAMP/
Default folder htdocs: /Applications/MAMP/htdocs/

3.2 Menjalankan MAMP

3
Jalankan Server:
Buka MAMP dari Applications.
Klik tombol Start Servers.
Apache dan MySQL akan berjalan (lampu indikator hijau).
Browser akan terbuka otomatis ke http://localhost:8888/MAMP/

3.3 Menempatkan File Aplikasi

4
Copy File:
Extract alfadh-umrah-app.zip ke:
/Applications/MAMP/htdocs/alfadh-umrah-app/
(Buka Finder → Tekan Cmd + Shift + G → ketik path di atas)

3.4 Import Database

5
Buka phpMyAdmin MAMP:
Akses http://localhost:8888/phpMyAdmin/
Klik Import → pilih file alfadh_umrah.sql → klik Go.
Catatan: Port MySQL MAMP default adalah 8889, bukan 3306.

3.5 Konfigurasi Port (Penting!)

Perhatian: MAMP menggunakan port berbeda dari XAMPP. Anda harus mengubah konfigurasi database.
6
Edit Config:
Buka /Applications/MAMP/htdocs/alfadh-umrah-app/includes/config.php
Ubah baris:
define('DB_HOST', 'localhost');
Menjadi:
define('DB_HOST', 'localhost:8889');
Jika menggunakan password MySQL MAMP, ubah juga DB_PASS.
Default MAMP: user root, password root.

3.6 Mengakses Aplikasi

7
Buka Browser:
Ketik http://localhost:8888/alfadh-umrah-app/
Halaman login akan muncul.

BAB IV — Instalasi di Linux (LAMPP / XAMPP)

4.1 Instalasi XAMPP di Linux

1
Download XAMPP for Linux:
wget https://sourceforge.net/projects/xampp/files/XAMPP%20Linux/8.2.4/xampp-linux-x64-8.2.4-0-installer.run
Atau download dari https://www.apachefriends.org
2
Berikan Permission & Install:
Buka Terminal (Ctrl + Alt + T)
cd ~/Downloads
chmod +x xampp-linux-x64-*.run
sudo ./xampp-linux-x64-*.run
Ikuti wizard instalasi GUI yang muncul.

4.2 Menjalankan XAMPP

3
Start Server:
sudo /opt/lampp/lampp start
Untuk menghentikan:
sudo /opt/lampp/lampp stop
Untuk restart:
sudo /opt/lampp/lampp restart
Permission Folder: Jika terjadi error permission saat extract file ke htdocs, jalankan:
sudo chmod 777 -R /opt/lampp/htdocs/

4.3 Menempatkan File Aplikasi

4
Extract ke htdocs:
sudo unzip alfadh-umrah-app.zip -d /opt/lampp/htdocs/
Atau gunakan file manager dengan sudo:
sudo nautilus /opt/lampp/htdocs/ (Ubuntu)
sudo dolphin /opt/lampp/htdocs/ (KDE)

4.4 Import Database

5
Via phpMyAdmin:
Buka browser → http://localhost/phpmyadmin
Klik Import → pilih alfadh_umrah.sql → Go.

Alternatif via Terminal:
sudo /opt/lampp/bin/mysql -u root -p
CREATE DATABASE alfadh_umrah;
USE alfadh_umrah;
SOURCE /opt/lampp/htdocs/alfadh-umrah-app/alfadh_umrah.sql;

4.5 Konfigurasi (Jika Diperlukan)

6
Edit Config:
sudo nano /opt/lampp/htdocs/alfadh-umrah-app/includes/config.php
Default XAMPP Linux tidak memiliki password MySQL (kosong).
Jika Anda mengubahnya, sesuaikan DB_PASS.
Tekan Ctrl + X → Y → Enter untuk menyimpan.

4.6 Mengakses Aplikasi

7
Buka Browser:
http://localhost/alfadh-umrah-app/
Jika menggunakan port berbeda, sesuaikan URL-nya.
Auto-start XAMPP: Tambahkan ke startup dengan mengedit sudo nano /etc/rc.local dan tambahkan baris /opt/lampp/lampp start sebelum exit 0.

BAB V — Panduan Admin (Super User)

ROLE: ADMINISTRATOR

5.1 Login sebagai Admin

1
Buka aplikasi di browser.
Masukkan Username: admin
Masukkan Password: password
Klik tombol MASUK.

5.2 Dashboard Admin

Setelah login, Anda akan melihat Dashboard dengan informasi:

  • Total Jamaah: Jumlah seluruh jamaah terdaftar
  • Jamaah Lunas: Yang sudah membayar penuh
  • Pembayaran Bertahap: Yang masih mencicil
  • Total Pemasukan: Seluruh uang masuk dari pembayaran

Dashboard juga menampilkan grafik batang pemasukan per paket dan grafik donut status pembayaran.

5.3 Manajemen Paket Umrah

Menambah Paket Baru

A
Klik menu Paket Umrah di sidebar kiri.
Klik tombol + Tambah Paket.
Isi form:
  • Nama Paket: Contoh: "Umrah Reguler Ramadhan 2026"
  • Kode Paket: Contoh: "UMR-RAM-001" (unik, tidak boleh sama)
  • Harga: Angka tanpa titik/koma, contoh: 35000000
  • Durasi: Jumlah hari, contoh: 12
  • Keberangkatan: Tanggal berangkat
  • Kamar: Quad (4 org), Triple (3 org), Double (2 org)
  • Kuota: Maksimal jamaah, contoh: 100
  • Fasilitas: Tiket, hotel, makan, bus, dll
Klik Simpan.

Mengedit & Menghapus Paket

B
Di tabel daftar paket, klik ikon pensil (edit) untuk mengubah data.
Klik ikon tong sampah (hapus) untuk menghapus paket.
Hati-hati: Menghapus paket akan mempengaruhi data jamaah yang terdaftar di paket tersebut!

5.4 Manajemen Data Jamaah

Menambah Jamaah

A
Klik menu Data Jamaah → + Tambah Jamaah.
Isi data lengkap:
  • Kode Jamaah: Format unik, contoh: "JMH-001"
  • Nama Lengkap: Nama sesuai KTP
  • Jenis Kelamin, TTL, No. KTP, Passport
  • Alamat & Kontak: Untuk komunikasi
  • Paket Umrah: Pilih dari daftar paket aktif
  • Sales: Petugas yang menangani jamaah ini
  • Metode Bayar: Pilih "Lunas" atau "Bertahap"
Klik Simpan. Harga paket akan otomatis terisi.

Memantau Progress Pembayaran

Di tabel jamaah, terdapat kolom Progress berupa bar hijau/kuning yang menunjukkan persentase pembayaran:

  • ■ Hijau = Lunas atau mendekati lunas
  • ■ Kuning = Masih dalam proses cicilan

Kolom Sisa menampilkan nominal yang masih harus dibayar (merah = ada tunggakan, hijau = sudah lunas).

5.5 Manajemen Pembayaran

Input Pembayaran

A
Klik menu Pembayaran.
Di bagian kiri, pilih Jamaah dari dropdown.
Info otomatis muncul: Harga Paket, Total Terbayar, Sisa Pembayaran.
Isi form pembayaran:
  • Tanggal Bayar: Default hari ini
  • Jumlah Bayar: Nominal yang dibayarkan
  • Jenis: DP / Cicilan / Pelunasan / Lunas
  • Cicilan Ke-: Isi jika pembayaran cicilan (0 untuk DP/lunas)
  • Metode: Transfer / Cash / Debit
  • Keterangan: Catatan tambahan
Klik Simpan Pembayaran. Nomor kwitansi akan generate otomatis.

Cetak Kwitansi

B
Di tabel riwayat pembayaran, klik ikon printer.
Halaman kwitansi akan terbuka di tab baru.
Klik tombol Cetak Kwitansi atau tekan Ctrl + P.
Kwitansi memuat: watermark, stamp "LUNAS", terbilang, dan tanda tangan.

5.6 Laporan & Rekapitulasi

A
Klik menu Laporan.
Gunakan Filter untuk menyaring data:
  • Paket: Pilih paket tertentu atau semua
  • Sales: Filter berdasarkan petugas sales
  • Status Bayar: Lunas / Bertahap
  • Periode: Rentang tanggal pembayaran
Klik Filter untuk menerapkan.
Klik Cetak untuk print laporan (tombol print browser).

5.7 Manajemen Sales

Menambah Sales Baru

A
Klik menu Manajemen Sales → + Tambah Sales.
Isi form:
  • Nama Lengkap: Nama sales
  • Username: Untuk login (unik)
  • Password: Default "password" (bisa diubah nanti)
  • No. HP & Email: Kontak sales
  • Status: Aktif / Nonaktif
Klik Simpan. Sales bisa langsung login dengan username tersebut.

Melihat Performa Sales

Tabel sales menampilkan:

  • Jamaah: Berapa jamaah yang ditangani
  • Penjualan: Total uang masuk dari sales tersebut

Data ini juga tampil di Dashboard Admin pada bagian "Performa Sales".

Tips Admin: Rutin cek menu Laporan setiap minggu untuk memantau cash flow. Nonaktifkan sales yang tidak aktif agar tidak bisa login.

BAB VI — Panduan Sales

ROLE: SALES / PETUGAS

6.1 Login sebagai Sales

1
Buka aplikasi di browser.
Masukkan Username dan Password yang diberikan admin.
Contoh: sales1 / password
Klik MASUK.

6.2 Dashboard Sales

Setelah login, tampilan Dashboard Sales menunjukkan:

  • Jamaah Saya: Total jamaah yang ditangani
  • Total Penjualan: Uang masuk dari transaksi Anda
  • Transaksi Hari Ini: Berapa kwitansi dibuat hari ini

Di bawahnya ada daftar jamaah dengan progress bar pembayaran dan riwayat kwitansi terbaru.

6.3 Melihat Jamaah

A
Klik menu Jamaah Saya.
Tabel menampilkan semua jamaah yang ditangani.
Perhatikan kolom:
  • Progress: Persentase pembayaran (visual bar)
  • Sisa: Nominal yang belum dibayar
  • Status: Lunas (hijau) atau Bertahap (kuning)

6.4 Membuat Kwitansi Pembayaran

Ini adalah fitur utama Sales. Berikut langkah lengkapnya:

Langkah 1: Pilih Jamaah

A
Klik menu Buat Kwitansi.
Di bagian kiri, pilih Jamaah dari dropdown.
Informasi akan muncul otomatis:
  • Harga Paket (total yang harus dibayar)
  • Total Terbayar (sudah masuk berapa)
  • Sisa Pembayaran (yang masih kurang)

Langkah 2: Isi Detail Pembayaran

B
  • Tanggal Bayar: Default hari ini, bisa diubah jika bayar kemarin
  • Jumlah Bayar: Nominal uang yang diterima (tidak boleh lebih dari sisa)
  • Jenis Pembayaran:
    • DP = Uang muka pertama kali
    • Cicilan = Pembayaran angsuran (isi "Cicilan Ke-")
    • Pelunasan = Pembayaran terakhir (masih ada sisa sedikit)
    • Lunas = Bayar penuh langsung
  • Metode Bayar: Transfer Bank / Cash / Kartu Debit
  • Keterangan: Contoh: "Transfer dari BCA" atau "Bayar di kantor"

Langkah 3: Simpan & Cetak

C
Klik tombol Buat Kwitansi.
Sistem akan generate nomor unik, contoh: KWT-20260521-0001
Notifikasi sukses akan muncul dengan link Cetak Kwitansi.
Klik link tersebut → halaman kwitansi terbuka.
Klik Cetak Kwitansi atau tekan Ctrl + P.
Berikan kwitansi cetak kepada jamaah sebagai bukti sah.
Catatan Penting: Nomor kwitansi bersifat unik dan tidak bisa diubah. Pastikan data jumlah bayar sudah benar sebelum klik Simpan.

6.5 Melihat Riwayat Kwitansi

D
Di halaman Buat Kwitansi, bagian kanan menampilkan riwayat kwitansi Anda.
Klik ikon printer untuk mencetak ulang kwitansi yang pernah dibuat.
Data terurut dari yang terbaru ke terlama.

6.6 Batasan Akses Sales

Sales TIDAK BISA:

  • ❌ Menambah/mengedit paket umrah
  • ❌ Menambah/menghapus data jamaah (hanya bisa melihat)
  • ❌ Melihat data jamaah milik sales lain
  • ❌ Mengakses laporan keuangan keseluruhan
  • ❌ Mengelola user/admin lain

Sales HANYA BISA:

  • ✅ Melihat jamaah yang ditangani
  • ✅ Membuat kwitansi pembayaran
  • ✅ Mencetak kwitansi
  • ✅ Melihat riwayat kwitansi sendiri
Tips Sales: Selalu konfirmasi nominal bayar dengan jamaah sebelum input. Jika jamaah bayar lunas langsung, pilih jenis "Lunas" agar status otomatis berubah.

BAB VII — Manajemen Pembayaran & Kwitansi

7.1 Alur Pembayaran Bertahap

Berikut skenario pembayaran bertahap yang umum:

TahapJenisCicilan Ke-Contoh Nominal
1DP0Rp 10.000.000
2Cicilan2Rp 5.000.000
3Cicilan3Rp 5.000.000
4Pelunasan0Rp 15.000.000

Setelah total bayar = harga paket, status jamaah otomatis berubah menjadi Lunas.

7.2 Struktur Nomor Kwitansi

Format: KWT-YYYYMMDD-XXXX

  • KWT = Prefix Kwitansi
  • YYYYMMDD = Tanggal pembuatan (20260521)
  • XXXX = Nomor urut per hari (0001, 0002, dst)

Contoh: KWT-20260521-0001 artinya kwitansi pertama dibuat tanggal 21 Mei 2026.

7.3 Format Kwitansi Cetak

Kwitansi yang tercetak memuat elemen resmi:

  • Header: Nama PT, logo area, dan tagline
  • Nomor kwitansi yang unik
  • Data jamaah lengkap (nama, KTP, alamat, HP)
  • Nominal dalam angka dan terbilang (ejaan)
  • Detail paket umrah yang dibeli
  • Metode dan tanggal pembayaran
  • Tanda tangan jamaah dan petugas
  • Stamp "LUNAS TERBAYAR" berbentuk lingkaran
  • Watermark "ALFADH" transparan
  • Footer: informasi legal dan izin travel

7.4 Status Pembayaran Otomatis

KondisiStatus SistemWarna Badge
Belum ada pembayaranBertahapKuning
Sudah bayar sebagianBertahapKuning
Total bayar >= Harga paketLunas (auto)Hijau

7.5 Cara Cetak Ulang Kwitansi

1
Login sebagai Admin atau Sales.
Buka menu Pembayaran (Admin) atau Buat Kwitansi (Sales).
Cari kwitansi di tabel riwayat.
Klik ikon printer → halaman kwitansi terbuka.
Tekan Ctrl + P → pilih printer → Cetak.

BAB VIII — Pemecahan Masalah (Troubleshooting)

8.1 Tidak Bisa Login

GejalaPenyebabSolusi
"Username atau password salah" Salah ketik / Caps Lock aktif Periksa Caps Lock, coba lagi. Default: admin/password
"Akun dinonaktifkan" Status user diubah ke "nonaktif" Hubungi admin untuk mengaktifkan kembali
Halaman login terus muncul Session/cookie browser bermasalah Hapus cache browser (Ctrl + Shift + Delete) → pilih "Cookies"

8.2 Database Error / Koneksi Gagal

GejalaPenyebabSolusi
"Koneksi gagal" MySQL tidak berjalan Buka XAMPP Control Panel → Start MySQL
"Access denied" Password MySQL salah Edit includes/config.php → sesuaikan DB_PASS
"Unknown database" Belum import SQL Import ulang file alfadh_umrah.sql via phpMyAdmin
"Table doesn't exist" Import SQL tidak lengkap Hapus database → import ulang file SQL

8.3 Kwitansi Tidak Tercetak

1
Periksa Popup Blocker:
Browser mungkin memblokir tab baru. Klik ikon popup blocker di address bar → Allow.

Periksa Printer:
Pastikan printer terhubung dan tidak error.

Cetak ke PDF:
Jika tidak ada printer, pilih "Save as PDF" di dialog print (Ctrl + P).

8.4 Tampilan Rusak / CSS Tidak Load

1
Refresh Cache:
Tekan Ctrl + F5 (Windows/Linux) atau Cmd + Shift + R (Mac).

Cek Koneksi Internet:
Bootstrap dan Font Awesome di-load dari CDN. Pastikan internet aktif.
Alternatif: Download file CSS/JS dan simpan di folder assets/.

8.5 Lupa Password Admin

1
Reset via phpMyAdmin:
Buka http://localhost/phpmyadmin
Pilih database alfadh_umrah → tabel users.
Cari user admin → klik Edit.
Pada kolom password, masukkan:
$2y$10$92IXUNpkjO0rOQ5byMi.Ye4oKoEa3Ro9llC/.og/at2.uheWG/igi
Ini adalah hash untuk password "password".
Klik Go untuk menyimpan.

8.6 Error 404 / File Not Found

1
Periksa Folder:
Pastikan folder aplikasi benar-benar di htdocs/alfadh-umrah-app/
Periksa URL:
Pastikan URL benar: http://localhost/alfadh-umrah-app/
(Jangan sampai ada typo atau spasi berlebih)
Periksa Apache:
Pastikan Apache running di XAMPP Control Panel.

BAB IX — Keamanan & Backup

9.1 Mengubah Password Default

PENTING: Segera ubah password default setelah pertama kali login untuk keamanan!
1
Untuk Admin:
Login sebagai admin → Manajemen Sales → Edit user admin (jika ada).
Atau ubah langsung via phpMyAdmin di tabel users.

Untuk Sales:
Hubungi admin untuk mengubah password Anda.
Admin bisa edit password di menu Manajemen Sales.

9.2 Backup Database

Via phpMyAdmin (Cara Mudah)

A
Buka http://localhost/phpmyadmin
Klik database alfadh_umrah.
Klik tab Export → pilih Quick → format SQL.
Klik Go → file SQL akan di-download.
Simpan file backup di tempat aman (cloud/external drive).

Via Command Line (Cara Advanced)

B
Windows (XAMPP):
Buka Command Prompt → jalankan:
cd C:\xampp\mysql\bin
mysqldump -u root alfadh_umrah > C:\backup\alfadh_backup_2026.sql

Linux:
sudo /opt/lampp/bin/mysqldump -u root alfadh_umrah > ~/backup/alfadh_backup.sql

Mac (MAMP):
/Applications/MAMP/Library/bin/mysqldump -u root -p alfadh_umrah > ~/Desktop/alfadh_backup.sql

9.3 Restore Database

1
Via phpMyAdmin:
Buka phpMyAdmin → klik database alfadh_umrah.
Centang semua tabel → pilih Drop (hapus semua).
Klik tab Import → pilih file backup SQL → Go.

Via Command Line:
mysql -u root alfadh_umrah < backup_file.sql

9.4 Backup File Aplikasi

1
Windows:
Copy folder C:\xampp\htdocs\alfadh-umrah-app\ ke flashdisk/cloud.

Mac:
Copy folder /Applications/MAMP/htdocs/alfadh-umrah-app/

Linux:
sudo cp -r /opt/lampp/htdocs/alfadh-umrah-app ~/backup/

9.5 Keamanan yang Sudah Diterapkan

AspekImplementasi
